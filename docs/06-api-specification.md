# 06 — API Specification

Base path `/api/v1`. The live, exact contract is generated by FastAPI at `/api/docs` (Swagger) once each phase is built; this document is the plan it must satisfy.

## 1. Conventions

| Topic | Rule |
|---|---|
| Auth | `Authorization: Bearer <access JWT>`; refresh via HttpOnly cookie on `/auth/refresh` |
| Branch scope | Staff endpoints that act on a branch take `X-Branch-Id`; checked against `user_branches` |
| Tenant | **Never** accepted in a body. Public: from `{slug}`. Staff: from membership. Super Admin: from path `{tenant_id}` |
| Idempotency | `Idempotency-Key: <uuid>` **required** on endpoints marked 🔁 |
| Pagination | `?page=1&page_size=20` → `{ items, page, page_size, total }` |
| Filtering / sort | `?q=`, field filters, `?sort=-created_at` |
| Errors | `{ "error": { "code": "TABLE_ALREADY_ASSIGNED", "message": "...", "details": {...} } }` with proper HTTP status |
| Money | Strings with 2 decimals in JSON (`"520.00"`) to avoid float rounding |
| Time | ISO-8601 UTC (`2026-11-16T14:05:00Z`); responses that drive timers include `server_time` |
| Versioning | Breaking changes → `/api/v2`; additive changes in place |

Auth column legend: **P** public · **C** customer · **S:perm** staff with permission · **SA** super admin · **W** webhook (signature).

## 8. Socket.IO

Namespace `/rt`. Connect with `auth: { token }` (staff/customer JWT or table-session token). Client emits `subscribe { room }`; server authorises each room (see [doc 01 §6](01-system-architecture.md#6-real-time-design)).

**Implemented so far (Phases 6–7):** `subscribe {kind}` with `branch_staff` (`branch_id`; membership + branch access checked), `user` (always the caller's own room), `branch_queue` (`tenant_id, branch_id`; public, no personal data) and `table_session` (`token` = table token from order ID + PIN). Events: `tables.changed`, `queue.changed`, `reservations.changed`, `orders.changed` (payload `{branch_id[, order_id, status]}` — clients refetch) and `notification` (`{event, title, body, link}`) to the user room.

| Event | Room | Payload (key fields) |
|---|---|---|
| `queue.updated` | staff | `entries[]` summary |
| `queue.position_changed` | queue_entry | `position, eta_minutes` |
| `queue.table_ready` | queue_entry | `table_label` |
| `table.status_changed` | staff, public (counts only) | `table_id, status` |
| `availability.changed` | public | `branch_id, free_by_size, wait_minutes` |
| `reservation.created` · `.confirmed` · `.arrived` · `.expired` | staff / customer | `reservation_id, status` |
| `order.placed` | staff, kitchen | `order_id, number, table` |
| `order.status_changed` | staff, kitchen, session | `order_id, status, at` |
| `sla.started` | session, staff | *Phase 8: sent as `orders.changed` (clients refetch the order with its `sla`)* |
| `discount.changed` | session, staff | *Phase 8: sent as `orders.changed` at each boundary by the worker* |
| `bill.updated` | session, staff | `bill_id, totals` |
| `inventory.low_stock` | staff | `item_id, on_hand, reorder_level` |
| `notification.new` | user | `notification` |
